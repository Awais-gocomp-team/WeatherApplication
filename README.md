# Weather App 🌦️

An Android weather application built using **Kotlin**, **Retrofit**, and the **MVVM architecture**. 
The app fetches real-time weather data from a public Weather API and displays current conditions, 
temperature, humidity, and forecast details in a clean, user-friendly interface.

## 📱 Features

- 🌍 Search weather by city name
- 📍 Get weather for current location (GPS)
- 🌡️ Displays temperature, humidity, wind speed, and pressure
- 📅 5-day weather forecast
- 🎨 Clean and responsive UI
- ⚡ Fast API calls using Retrofit
- 🔄 Pull-to-refresh support
- ❌ Error handling for no internet / invalid city

## 🛠️ Built With

- **Kotlin** – Primary language
- **Retrofit2** – Networking & API calls
- **Gson Converter** – JSON parsing
- **Coroutines** – Asynchronous programming
- **MVVM Architecture** – Clean code separation
- **LiveData / ViewModel** – Lifecycle-aware data handling
- **Glide** – Loading weather icons
- **OpenWeatherMap API** – Weather data source

## 📡 API Used

This project uses the [OpenWeatherMap API](https://openweathermap.org/api) to fetch live weather data.
